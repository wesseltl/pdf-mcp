How reliable extraction is set up

Show it what to find, then test the answers.

  1. 01Name the fields

    Specify the columns you need, such as item, quantity, price, or sample ID.

  2. 02Extract the rows

    Read the table and keep a reference to the source of every value.

  3. 03Check the answers

    Compare the extracted rows with answers approved by a person.

  4. 04Handle uncertainty

    Use clean results and hold uncertain or unsupported documents for review.

Good fit

Best for document types you receive again and again.

  • Lab reports and certificates of analysis
  • Invoices, vendor statements, and operational reports
  • Tables that use the same columns across many files
  • Workflows where a person can check unusual results

Current boundary

Born-digital tables only.

  • No scans, OCR, handwriting, charts, or image-only PDFs
  • No password-protected files or manual data entry
  • No patient data or other special-category personal data
  • No accuracy claim for layouts outside the evaluation set
