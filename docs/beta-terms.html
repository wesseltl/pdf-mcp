Free Hosted Beta Terms

Effective 11 August 2026

These terms apply to the optional pdf-mcp hosted beta operated by Wessel ter Laak. The local pdf-agent-mcp software remains MIT licensed, local, and telemetry-free.

Beta access

The hosted beta is free, invitation-based, and intended for businesses and professionals evaluating agent-driven document extraction. Access uses an individual API key and may be limited, changed, suspended, or ended during the beta. There is no production availability or support SLA. The default allowance is 25 operations per calendar month.

Applications may open before the hosted endpoint is deployed. An application does not guarantee access or an invitation date. File uploads become available only after the applicant receives a verified endpoint, an individual key, and setup instructions.

API keys must not be shared, published, or used to bypass the allowance.

Accepted documents

Use only redacted or non-sensitive born-digital PDF or DOCX documents that you have the right to process.

Do not upload patient or health data, special-category personal data, government identifiers, credentials, passwords, payment-card data, malware, encrypted documents, or documents whose confidentiality requires a production processing agreement. Scanned PDFs and OCR are not supported.

Processing and measurement

Each selected document is uploaded only for the requested operation. Its temporary copy is deleted when that request completes or fails, and documents are not used for model training.

The service measures non-secret API key ID, timestamp, tool, PDF/DOCX type, upload byte count, page/table/warning counts, duration, and success or a bounded error code. It does not put raw API keys, source filenames, document contents, extracted text, or table cells in the usage ledger. Operational metrics are retained for up to 90 days.
